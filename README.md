# OU_APARTMENT
 Apartment Rental Website

A website for searching apartments and viewing detailed rental listings.

<p> <img src="https://img.shields.io/badge/Flask-000000?style=flat&logo=flask&logoColor=white" /> <img src="https://img.shields.io/badge/Bootstrap-7952B3?style=flat&logo=bootstrap&logoColor=white" /> <img src="https://img.shields.io/badge/MySQL-4479A1?style=flat&logo=mysql&logoColor=white" /> </p>
 Features
 Search apartments
 View detailed apartment listings
 Tech Stack
Layer	Technology
Backend	Flask
Frontend	Bootstrap
Database	MySQL
 Getting Started
 
```bash
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
flask run
```
Add a .env file with your MySQL database credentials.
